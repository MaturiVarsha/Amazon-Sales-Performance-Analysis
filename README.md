# Amazon Sales Performance Analysis 📊

## Project Overview

This project analyzes one month of Amazon order-level sales data using Microsoft Excel.

The purpose of the project is to transform raw sales data into meaningful business insights related to product performance, category performance, customer locations, payment methods, and order status.

An interactive Excel dashboard was developed using PivotTables, PivotCharts, formulas, and slicers to support data-driven decision-making.

---

## 🎯 Project Objective

The main objectives of this project are:

- Analyze Amazon sales performance
- Identify the highest-performing products and categories
- Analyze sales performance across customer locations
- Understand customer payment method preferences
- Analyze completed, cancelled, and pending orders
- Create PivotTables for business analysis
- Develop an interactive Excel dashboard
- Generate actionable business insights and recommendations

## 🔍 Project Methodology

### 1. Data Loading
- Imported the Amazon sales dataset into Excel.
- Reviewed the dataset structure and data types.

### 2. Data Cleaning & Validation
- Checked for duplicates and missing values.
- Standardized data formats.
- Validated Total Sales using Price × Quantity.

### 3. Data Preprocessing
Created calculated fields including:

- Month
- Day of Week
- Order Status Flag

### 4. Data Analysis

Created PivotTables to analyze:

- Category-wise Total Sales
- Product-wise Total Sales
- City-wise Total Sales
- Payment Method Usage
- Order Status Distribution
- Top Customers by Spending

### 5. Dashboard Development

Built an interactive Excel dashboard containing KPI cards, charts, and slicers.

## 💡 Key Insights

### Category Performance

Electronics generated the highest sales, followed by Home Appliances.

These two categories represent the major sales contributors in the analyzed dataset.

### Order Status

Out of 250 orders:

- 88 were completed
- 77 were cancelled
- 85 were pending

The relatively high number of cancelled and pending orders indicates an opportunity to improve order fulfillment.

### Product Performance

Product-level analysis was performed using PivotTables to identify the products generating the highest total sales.

### Customer Location

Location-level analysis was performed to identify strong and weak-performing customer locations.

### Payment Methods

Payment method analysis was performed to understand customer purchasing preferences.

---

## 🚀 Business Recommendations

1. **Focus on high-performing categories**
   - Prioritize inventory and promotional activities for Electronics and Home Appliances.

2. **Reduce cancelled orders**
   - Investigate factors such as product availability, pricing, delivery expectations, and order confirmation.

3. **Improve pending-order fulfillment**
   - Monitor pending orders and improve fulfillment processes to increase completed orders.

4. **Target strong-performing locations**
   - Focus marketing and sales activities on locations with stronger performance.

5. **Monitor payment preferences**
   - Use payment method insights to improve the customer purchasing experience.
